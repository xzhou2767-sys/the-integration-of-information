# 项目宪法 · 目标（Project Goals）

> 版本：1.0｜制定日期：2026-10-10｜地位：SDD（规范驱动开发）项目宪法之一，与 [project-tech-stack.md](project-tech-stack.md)、[project-roadmap.md](project-roadmap.md) 同级。
> 冲突裁决规则：本文与 `docs/PROJECT_SYSTEM.md`（现状权威源）冲突时，**现状以 PROJECT_SYSTEM.md 为准，目标与方向以本文为准**；修改本文需用户批准。

## 一、使命

跨平台（Android / Desktop）信息聚合平台：云端服务以**模拟正常用户行为**为主采集多平台信息，经清洗、去重、排序、AI 摘要后，通过 REST API 下发客户端信息流；用户以自然语言描述偏好，系统解析为关键词与展示模式实现个性化排序。

## 二、核心目标

1. **信息聚合**：多平台（学术/科技/人文/国际时事等 32 类目、20+ 来源）信息统一采集、去重、个性化排序下发。
2. **行为优先采集**：不依赖 API Key——优先模拟真实用户行为（浏览器 + 登录态），直连可用时才走 HTTP。
3. **云端代理零配置**：3xui 订阅由服务端自动解析/测速/择优，客户端永远直连云 API，零代理配置。
4. **成本导向**：全链路分级降档（摘要三档、视频三档、视觉模型六级降级链），密集计算由显式请求触发。
5. **视频内容提取**：把视频信息提取能力沉淀为可引用证据（转录/帧/总结）、MCP 工具与 Agent 应用三层形态。

## 三、非目标（当前不做）

- 配音与人声分离、自动成片、成品字幕压制（方向 C 非目标）。
- 多租户计费、密集视觉覆盖长视频。
- 微信视频号（已作为独立分支项目移出，见 `docs/branch-wechat-channels.md`）。

## 四、核心设计原则（宪法级约束，变更需用户批准）

1. **采集不依赖 API Key**——模拟真实用户行为优先。
2. **代理在云端**——客户端零配置。
3. **成本导向**——分级降档，默认只跑最低成本档。
4. **模块化设计**——系统可扩展、可维护（core / server / client-app 三模块分层，DTO 默认值兼容）。
5. **数据安全与用户隐私优先**——凭据不进命令行/文档/git；凭据读取一律需用户显式批准。
6. **信息类目定制必须有 GUI**（用户长期约束：客户端提供类目自定义界面）。

## 五、成功度量（对齐 PROJECT_SYSTEM 各节验收口径）

- 信息流：类目覆盖 32、来源观测 13+，feed 亚秒响应（缓存热）。
- 决策核心 V2：V1/V2 压测对比零错误后灰度，观测数据积累后评估全量。
- 视频三方向：按各自评分表五维度，总分 ≥85 且各维度 ≥ 最低分才放行。
